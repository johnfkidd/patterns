# Overview

The DDD projects are going to be built using various AI Agents including MS Copilot and GitHib Copilot.

The idea is to show security by design techniques for a DDD product called order management. This is just a simple product to demo the ideas and concepts and to tiral the LLMs.

## Architecture Overview

An onion architecture that allows a client to access the order management domains via web api calls.

The system will have 2 domains; one for placing orders and one for sales.

## Technology Overview

In order to get a good feel for using AI to write the code we will provide 4 languages with appropriate frameworks for each.

* Python
* Scala
* Go
* Rust
